# Solstice
마크다운 노트 안에서 코드를 실행하는 노트 앱. 무료로 사용할 수 있습니다.
A note-taking app that runs code inside your markdown notes. Free to use.

- Windows 10/11 (64-bit)
- Download: see the latest release on the Releases page
- Windows SmartScreen may warn about an unknown publisher (the installer is not code-signed yet). Choose "More info" → "Run anyway".
- Supported languages: Python, JavaScript, SQL, C++, Bash, PowerShell
